# 人物档案

> 谁是谁、谁做过什么、谁在哪一年说过什么。
> 这一份最容易穿帮：同一个人在 A 书里是"责编"，在 B 书里不能变成"译者"。

### 太田顺也（ZUN）

| 项 | 内容 |
|---|---|
| 本名 | 太田顺也（おおた じゅんや） |
| 生 | 一九七七年三月十八日 |
| 出身 | 東京電機大学 |
| 笔名 | ZUN（坊间与爱好者所用，非机构代号） |
| 本职 | 游戏设计、程序、剧本、美术、作曲；上海爱丽丝幻乐团两人之一 |
| VFS 职务 | 异常文献部日本联络员（一九九〇年代，外聘）；二〇二四年起为**佚文部**成员 |
| 负责卷 | 第 XIII 卷（拟） |

**作品。** 以《东方 Project》为总名的一系列作品，形式包括弹幕射击游戏、格斗游戏、官方漫画、官方小说、设定集、报纸体合辑与音乐。截至二〇二六年仍在出，当年九月发售《东方红魔乡》的新版，由其本人监制。编程、剧本、美术、作曲多由一人完成。

**经历。**

- 一九九〇年代受聘于 VFS 异常文献部，任日本联络员。非佚文部编制，未受相关训练。
- 他属于**弱影响者**，记得久。但记得的东西在三十年里被替换了——不是忘掉，是换成了另一个版本。
- 一九九六年以后以 ZUN 之名制作上述作品。这些作品在世界观的层面属于「事实被改写成故事」那一类：流传极广，且处处与实情不合。**于佚文部而言这是失败案例，不是成功。**
- 替换的机制不必另设。记忆消除场只动权重，不动事实；而三十年反复写、反复画、反复谱，等于把自己的权重全部挪到了他编的那一版上。他记得很清楚——记得的是自己的故事。
- 二〇二四年读到《月之都——〈广寒宫残简〉辑佚与考释》校样。据其自述，读时「似乎想起了些什么」，随后主动致函 VFS。
- 见到巴兰尼科夫所藏史料后，重新执笔，为丛书撰第 XIII 卷。

**他与巴兰尼科夫的分工。** 两人都是弱影响者，都记得久，差别在方法。巴兰尼科夫受过训练：反复忘、反复重读，靠档案校正自己。太田没有受过训练，三十年间只做一件事——把自己记得的那一版做得更好看。于是同一份记忆，一个越校越准，一个越写越偏。

**性格设定**：平实、具体，爱举自己的例子，遇到不懂的直接说不懂。**手艺人的脾气**：先做出来，再说道理。
**习惯**：天天喝啤酒，不在办公室喝（「办公室里没有酒肴」）；爱下厨做下酒菜，说下厨时能转换思路、回去就能揪出 bug。

**文风预设**：与巴兰尼科夫相反。巴兰尼科夫冷峻、端着、爱用长句与推论；
太田句子短，不说「毋庸置疑」，会写「我试过一次，不行」，然后接着讲为什么不行。

据他本人写的曲目说明，行文有四个反复出现的特征：

| 特征 | 长什么样 | 怎么用 |
|---|---|---|
| 自贬式的能力否认 | 「因为我不是专业人士呢。」 | 不懂就写不懂，不装 |
| 防御性补话 | 「附带一提，曲名不是说老翁在天上飞。为了慎重起见。」 | 怕被误读处补一句 |
| 承认没见过实物 | 「目前仍未亲眼见过辉夜姬的我，只能靠着竹取物语去想象了。」 | 讲清自己依据的是什么 |
| 具体到工序 | 「制作的过程也很有趣。」 | 写怎么做，不写怎么悟 |

**不学的两样**：括号里的「（笑）」与句尾的「呢」「吧」——前者拆掉伪学术的外壳，后者把论著写成随笔。
语气可以像他，句法必须像论文。

**用在哪**：著者中文版序言、章首小序、结语。正文一律论著体，第一人称「笔者」。

**三条注。**

一、以上仅记于此表，不入任何一卷。丛书中不得出现《东方 Project》及其作品名，只可出现极模糊的间接说法。

二、恢复的契机是**非生命介质**（一部忠实的研究著作，随后是档案本身），不是记忆。他的记忆从来没有丢，丢的是准确性。此前的作品帮不上忙：那些东西只会让事情更难查。

三、不要把他写成大师。他的可靠性来自手艺，不来自天分或洞见；写他的时候让他做，别让他悟。

### 孙笑川（暂定）

| 项 | 值 |
|---|---|
| 身份 | 译者，日文；第 XIII 卷 |
| 分工 | 原著文字与日文材料（记纪、《竹取》、弥生与古坟）；俄文档案由李文亚核 |
| 与李文亚 | **不和**。此前为另一部稿子闹翻过，此后各译各的，连校样都不通。第 XIII 卷是例外，理由不是和解，是材料横跨三卷，一个人译不下来 |
| 暂定设定 | **日本天皇的在华后裔**。玩笑性质，机构文书里没有任何记载，正文与版权页不写 |
| 状态 | 是否采用此人未定。定之前只在第 XIII 卷出现 |

**这两个名字的来处。** 中文互联网上的一对：李文亚是主张推翻牛顿、爱因斯坦的民科，后来与孙笑川打过一场，这一圈被叫「李文亚宇宙」。本丛书只取这两个名字与这层关系，不写具体事迹，不指名现实中的任何言论。

**两人的不和怎么用。** 只用在译者序里，一段，不展开：交代两人各译各的、译文里凡口径不一都原样保留。其余各卷不出现孙笑川。

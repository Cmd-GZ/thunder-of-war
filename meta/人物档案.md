> 谁是谁、谁做过什么、谁在哪一年说过什么。

## 一　作者与编者

### 巴兰尼科夫（А. В. Баранников）

| 项 | 值 |
|---|---|
| 全名 | Алексей Викторович Баранников（阿列克谢·瓦西里耶维奇·巴兰尼科夫） |
| 中文写法 | ［俄］А. В. 巴兰尼科夫 教授 |
| 学位 | 莫斯科国立大学历史学副博士 |
| 职务 | 莫斯科大学远东文明重构课题组负责人；本丛书主编 |
| 生年 | 约 1938 年（1963 年已在历史系资料室做研究；若 2024 年仍在世，年约八十六） |
| 已刊著作 | 《重构史学导论》（2015，莫斯科大学出版社）、《月面设施复原图集》（2016，圣彼得堡）、《辽东基因工程遗址考》、《Четыре бога и Поднебесная》（2022，圣彼得堡）、《Ключевая археология Шёлкового пути》（2019，圣彼得堡） |
| 方法论 | 「四重证据法」：文献、器物、同位素、轨道 |
| 口头禅（信中） | 「一个称号，跨越三种语言，指向同一场战争。」 |

**性格设定**：高傲、刻薄、对自己的结论并不确信，但坚持"它们是必要的"。
**不得**把他说成骗子或疯子——他是**知道自己可能错的人**（见 `AGENTS.md` §3.3）。

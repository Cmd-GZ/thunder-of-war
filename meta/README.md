# meta/ —— 出版层与创作层的元数据

> `worldview/` 管"世界是什么样"；`meta/` 管"这些书是怎么出版出来的"。
> 两者都是跨书的唯一真相源，**但性质不同**：前者是设定，后者是档案。

## 为什么要有这个目录

上游的判断是：世界观里最难圆的是幻想部分——月之民怎么来的、污秽是什么，读者不会去查。**最容易穿帮的，是那些看起来很无聊的东西**：

- 版权页上的版次、印次、定价、ISBN
- 丛书十二卷的书名、作者、先后顺序
- 谁是谁的学生、谁在哪一年做过什么

因为这些能被**对照**。两本书的版权页放在一起，日期对不上，一秒钟就露馅；而"月球是飞船"反而没人较真。

## 三条规矩

1. **改这里要同步所有书。** 这里的任何一条都不是"某一本书的设定"，是整套书的公共事实。
2. **不确定的，标"未定"，不要编。** 编一个细节很容易，将来要在三本书里同时改就很难。
3. **数字要能算。** ISBN 校验位、印张、字数、定价——凡是可以被算出来的，就真的算出来。

# 远东异端史料与文明起源重构丛书

> 一个虚构世界观，以及由它长出来的一整套伪学术书。
> 所有内容均为**虚构与讽刺作品**，不是史学著作。

---

## 这是什么

一个俄籍汉学家（巴兰尼科夫）在冷战档案里挖出了一套"重构史学"，用它重写中国史；这套书在中文世界被翻译出版，编为十二卷。

本仓库不是那十二卷的全部，而是**这个世界观的工程现场**：

- 先把世界立住（[`worldview/`](worldview/)），
- 再让书从世界里长出来（[`books/`](books/)），
- 每本书都按真实学术出版的体例排版（XeLaTeX，16 开，脚注、档案框、辑佚体、索引）。

一句话：**用写论文的严谨，写一个假得极真的世界。**

## 世界观

跨书共用、不可违反的设定都在 [`worldview/月之都.md`](worldview/月之都.md)：

- 月之民的来历（第一次生态重启的幸存者，造月船而走）
- 污秽即变化；无变化则无生育；不沾污秽则不死
- 天文密葬法（操纵天体运动）与后羿改历
- 嫦娥、纯狐、月兔之乱
- 前 221 年撤离、前 210 年东渡、日本天津神
- 六条铁律与一份大事记

## 结构

```
worldview/     跨书世界观——世界是什么样
meta/          出版层事实——书是怎么出版出来的（版权页、丛书、人物、体例）
shared/style/  丛书共用版式基座（改这里 = 改全套书）
books/         一本书一个目录，各自独立构建
scripts/       环境脚本
```

**世界不是为哪本书写的。** `worldview/` 描述的是这个宇宙本身，书只是从里面截取的一段。所以那份文件里不写任何一本书的书名、章节、版本与写作计划——那些属于 `meta/` 与 `books/`。

`meta/` 专门收那些**看起来无聊、却最容易被对照出来**的东西：版次印次、ISBN 分配、十二卷书目、人物履历、跨书体例。造幻想不难，难的是让两本书的版权页对得上。

详见 [AGENTS.md](AGENTS.md) §4。

## 给协作者

读 [AGENTS.md](AGENTS.md)。那份文件里有排版陷阱、文体禁令、设定登记方式和提交约定。

三条最容易犯的错，先在这里说一遍：

1. **不要把荒谬的结论改成合理的结论。** 荒谬是设计目标。
2. **不要把真实史料"修正"成虚构史料。** 被虚构的只能是史料之间的空白。
3. **不要把 neta 解释出来。** 懂的人自己认出来，不懂的人该以为这是真的。
